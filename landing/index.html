Pronto all'Uso

Installabile ovunque in pochi minuti

Nessuna configurazione complessa di database esterni o dipendenze: il container Docker include tutto il necessario.

🐳 Avvio Rapido Docker (Linux, Mac, Synology NAS)
Porta: 8000
docker run -d --name eurario -p 8000:8000 carlorigoni/eurario:latest
✓ Supporto Synology Container Manager ✓ Docker Compose integrato con Watchtower ✓ Volume dati persistente e snapshot
