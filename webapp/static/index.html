🖨️ Stampa Orario per Classe (Procedura 9)
Genera il fascicolo completo o l'orario di singole classi in formato A4 Orizzontale (1 classe per pagina). Supporta nativamente la fusione delle classi articolate (es. 3A con 3AM/3AR) e gli intervalli scolastici.
Tutte le classi
📄 Tabellone Docenti A3 (Procedura 12)
Genera il Tabellone Generale Completo di tutti i docenti dell'istituto in formato A3 Orizzontale (o A4 compatto). Include bande verticali alternate per giorno ed eliminazione automatica delle ore vuote in coda.
⚡ Ottimizzazione ore in coda attiva: le colonne orarie non utilizzate dall'intero istituto (es. Lun/Mer/Gio a 6 ore) vengono escluse per massimizzare la larghezza delle lezioni senza sprecare spazio.

🛡️ Conformità GDPR (Reg. UE 2016/679) & Privacy by Design
SmartTimetable opera esclusivamente on-premise all'interno della rete locale dell'Istituto, oppure su macchina virtuale (VM) o VPS controllata. Nessun dato dell'orario o anagrafico viene trasmesso a server cloud terzi. L'Istituto Scolastico o l'Ente che installa e utilizza il software agisce in via esclusiva come Titolare del Trattamento dei Dati Personali (Art. 4, n. 7 GDPR) ai sensi di legge.

🛠️ Come Applicare l'Aggiornamento
1. Aggiornamento Automatico con Watchtower:
Se il tuo server Docker ha il container containrrr/watchtower configurato, l'immagine verrà aggiornata automaticamente all'orario impostato senza alcun intervento manuale.
2. Aggiornamento Manuale Immediato:
Per aggiornare subito da terminale sul server o VPS, esegui nella cartella del progetto:
docker compose pull && docker compose up -d
💡 Sicurezza Dati: Tutti i dati, i vincoli e gli orari generati risiedono nei volumi persistenti e non vengono sovrascritti durante gli aggiornamenti dell'immagine.
